# ⏱️ Multi Time Tracker

Ein eleganter, browserbasierter Timer zur Überwachung der Redezeit mehrerer Speaker gleichzeitig. Entwickelt für Podiumsdiskussionen, Panels, Debatten und Live-Events.

![Multi Time Tracker](./screenshot.png)

---

## ✨ Features

- 🎯 **Bis zu 5 parallele Timer** – Jeder Redner hat seine eigene Stoppuhr
- 🎨 **Visuelle Zeitwarnungen** – Farbwechsel bei letzter Minute und Überschreitung
- 📱 **Responsive Design** – Funktioniert auf Desktop, Tablet und Mobile
- 🖥️ **Vollbildtauglich** – Optimiert für Projektoren und große Bildschirme
- ⚡ **Keine Installation** – Läuft direkt im Browser ohne Server
- 🌐 **Netzwerk-fähig** – Kann über lokalen Server für Publikum gestreamt werden
- 🎛️ **Test-Modus** – Zeitmanipulation für schnelle Tests verfügbar

---

## 🎨 Zeit-Anzeige & Farben

| Phase | Anzeige | Farbe | Hex-Code |
|-------|---------|-------|----------|
| **Normale Zeit** | `15:00` – `01:00` | Weiß | `#ffffff` |
| **Letzte Minute** | `00:59` – `00:00` | Gelborange | `#faec04` |
| **Überzogen** | `− 00:01` – `− ∞` | Rotorange | `#bb3f17` |
